# FOCO — Padrão de Nomenclatura em Português

## Regra oficial

Todo nome criado pela equipe deve ser escrito em português.

Isso inclui:

- arquivos;
- pastas;
- banco;
- schemas;
- tabelas;
- colunas;
- views;
- classes;
- funções;
- variáveis de domínio;
- serviços;
- repositórios;
- rotas;
- documentação;
- testes;
- mensagens.

## Exemplos de conversão

| Antes | Padrão FOCO |
|---|---|
| `ARCHITECTURE.md` | `ARQUITETURA.md` |
| `ROADMAP.md` | `ROTEIRO_DE_VERSOES.md` |
| `DATA_MODEL.md` | `MODELO_DE_DADOS.md` |
| `SECURITY.md` | `SEGURANCA.md` |
| `UX_UI.md` | `EXPERIENCIA_INTERFACE.md` |
| `BRAND_SYSTEM.md` | `IDENTIDADE_VISUAL.md` |
| `MAP_OPERATIONAL_AREAS.md` | `AREAS_OPERACIONAIS.md` |
| `REFERENCES.md` | `REFERENCIAS.md` |
| `source_system` | `sistema_origem` |
| `import_batch` | `lote_importacao` |
| `operational_unit` | `unidade_operacional` |
| `occurrence` | `ocorrencia` |
| `vehicle` | `viatura` |
| `operational_area` | `area_operacional` |
| `created_at` | `criado_em` |
| `updated_at` | `atualizado_em` |

## Exceções

Nomes obrigatórios de ferramentas podem permanecer no formato original:

- `Dockerfile`
- `package.json`
- `pyproject.toml`
- `requirements.txt`
- `__init__.py`
- `tsconfig.json`
- `vite.config.ts`

Nomes próprios de tecnologias também permanecem:

- React
- FastAPI
- PostgreSQL
- PostGIS
- Docker
