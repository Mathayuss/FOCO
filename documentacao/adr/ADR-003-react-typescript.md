# ADR-003 — React + TypeScript

**Status:** Accepted

## Contexto
O FOCO necessita dashboards, filtros cruzados, mapas, gráficos, tela cheia, drill-down e sala de situação.

## Decisão
Utilizar React com TypeScript.

## Motivos
- ecossistema maduro;
- componentização;
- tipagem;
- manutenção;
- integração com ECharts e mapas.

## Consequências
- disciplina de estado;
- contratos tipados;
- lógica de negócio deve permanecer no backend.
