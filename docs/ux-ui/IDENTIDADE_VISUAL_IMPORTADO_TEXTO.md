# FOCO — Identidade Visual

## Referência

O Manual de Identidade Visual do CBMMS é a referência normativa principal.

## Cores institucionais

### Goles
- HEX: `#D83135`
- RGB: 216, 49, 53

### Jalde
- HEX: `#FFCC29`
- RGB: 255, 204, 41

## Personalidade

O FOCO deve transmitir:

- prontidão;
- precisão;
- confiabilidade;
- disciplina;
- sobriedade;
- inteligência operacional;
- clareza.

## Marca

Não é permitido:

- distorcer;
- alterar cores;
- alterar proporções;
- redesenhar;
- separar elementos internos;
- aplicar sobre fundo sem contraste.

## Tipografia

Utilizar TheMix somente quando houver disponibilização/licenciamento institucional.

Fallback de interface:

```css
Arial, Helvetica, sans-serif
```

## Aplicação no produto

A marca deve aparecer em locais institucionais, como:

- acesso;
- barra principal;
- relatórios;
- sala de situação;
- tela Sobre.

Não repetir a marca em todos os cartões.
