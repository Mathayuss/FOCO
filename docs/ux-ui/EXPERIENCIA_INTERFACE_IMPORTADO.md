# FOCO — Experiência e Interface

## Direção visual

- painel escuro;
- institucional;
- alta legibilidade;
- alta densidade de informação;
- pouco ruído visual;
- filtros sempre visíveis;
- gráficos interativos;
- mapas analíticos.

## Navegação

- Visão Geral
- Evolução
- Tipificação
- Temporal
- Território
- SLA
- Viaturas
- Unidades
- Importações
- Integrações
- Qualidade dos Dados
- Configurações

## Regra de idioma

Todos os títulos, rótulos, mensagens, nomes de componentes de domínio e documentação devem usar português.

## Estados de tela

- Carregando
- Sem dados
- Dados parciais
- Dados demonstrativos
- Erro
- Integração indisponível
