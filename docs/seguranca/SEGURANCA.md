# FOCO — Segurança

## Regras principais

- menor privilégio;
- autenticação institucional;
- autorização no servidor;
- segredos fora do código;
- auditoria;
- validação de entrada;
- proteção de uploads;
- HTTPS;
- CORS restritivo;
- backups;
- restauração testada.

## Perfis previstos

- Administrador;
- Gestão;
- Comando;
- Unidade;
- Analista;
- Sala de Situação.

## Logs

Mensagens de domínio devem ser escritas em português.

Exemplos:

```text
Importação iniciada
Ocorrência duplicada identificada
Falha ao sincronizar sistema de origem
Área operacional sem geometria homologada
```
